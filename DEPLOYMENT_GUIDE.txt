1. SYSTEM REQUIREMENTS
================================================================================

MINIMUM REQUIREMENTS:

3. INSTALLATION STEPS (WINDOWS)
================================================================================

STEP 1: Clone or Download Project
──────────────────────────────────────────────────────────────────────────────

Option A - Using Git (Recommended):
  PowerShell> git clone https://github.com/yourusername/kidney-stone-detection.git
  PowerShell> cd Kidney_Stone_Detection_Project

Option B - Manual Download:
  1. Download project as ZIP from GitHub
  2. Extract to desired location
  3. Open PowerShell in the extracted folder

STEP 2: Create Virtual Environment
──────────────────────────────────────────────────────────────────────────────

  PowerShell> python -m venv .venv
  PowerShell> .\.venv\Scripts\Activate.ps1

  Expected output: (.venv) appears in terminal prompt

  NOTE: If you get execution policy error:
  PowerShell> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  Then retry the activation command

STEP 3: Upgrade pip
──────────────────────────────────────────────────────────────────────────────

  PowerShell> python -m pip install --upgrade pip
  PowerShell> python -m pip install --upgrade setuptools wheel

STEP 4: Install Dependencies
──────────────────────────────────────────────────────────────────────────────

  PowerShell> pip install -r requirements.txt

  This will install:
  ✓ Flask 3.1.3 (web framework)
  ✓ TensorFlow 2.20.0 (ML model)
  ✓ NumPy 2.1.3 (numerical computing)
  ✓ OpenCV 4.13.0.92 (image processing)
  ✓ Firebase Admin 6.9.0 (authentication)
  ✓ And other dependencies

  Installation time: 5-15 minutes (depending on internet speed)

STEP 5: Add Firebase Credentials
──────────────────────────────────────────────────────────────────────────────

  1. Copy serviceAccountKey.json to project root directory
     Location: C:\path\to\Kidney_Stone_Detection_Project\serviceAccountKey.json

  2. Verify the file exists:
     PowerShell> Test-Path serviceAccountKey.json
     Expected output: True

STEP 6: Verify Installation
──────────────────────────────────────────────────────────────────────────────

  PowerShell> python -c "import tensorflow; import firebase_admin; print('✓ Imports successful')"

  Expected output: ✓ Imports successful

  If error occurs, see Troubleshooting section

6. RUNNING THE APPLICATION
================================================================================

STEP 1: Activate Virtual Environment
──────────────────────────────────────────────────────────────────────────────

Windows:
  PowerShell> .\.venv\Scripts\Activate.ps1

macOS/Linux:
  $ source .venv/bin/activate

Expected: (.venv) prefix in prompt

STEP 2: Start the Flask Application
──────────────────────────────────────────────────────────────────────────────

Windows:
  PowerShell> python app.py

macOS/Linux:
  $ python app.py

Expected output:
  ⚠️ Primary load failed: corrupt configuration detected - skipping load_model
  ✓ Building custom top layers...
  ✓ Loading weights from h5py archive...
  ✓ Model loaded and compiled successfully!
  
   * Running on http://127.0.0.1:5000
   * Debug mode: on
   * Press CTRL+C to quit

──────────────────────────────────────────────────────────────────────────────

Open web browser and navigate to:
  http://localhost:5000

OR

  http://127.0.0.1:5000

You should see the KidneyStone AI homepage with:
  ✓ Navigation bar with theme toggle
  ✓ Hero section with "Start Detection" button
  ✓ Features section
  ✓ How It Works section
  ✓ About and Contact sections

STEP 4: Login / Register
──────────────────────────────────────────────────────────────────────────────

1. Click "Sign Up" to create account:
   - Enter email address
   - Create password
   - Verify email with code sent to email

2. Or click "Login" to access existing account

3. After login, click "Start Detection" or go to /upload

STEP 5: Upload and Analyze Image
──────────────────────────────────────────────────────────────────────────────

1. Go to upload page (/upload)
2. Select or drag-drop an ultrasound image:
   - Supported formats: PNG, JPG, JPEG, JFIF
   - Maximum size: 16MB
   - Recommended size: 512x512 pixels

3. Click "Analyze Image"
4. Wait for model inference (typically 2-5 seconds)
5. View results:
   - Detection status (Stone Detected ⚠️ or No Stone ✅)
   - Confidence percentage
   - Detailed description
   - Processing time

STEP 6: Stop the Application
──────────────────────────────────────────────────────────────────────────────

Press Ctrl+C in terminal to stop the Flask development server

8. DEPLOYMENT TO CLOUD
================================================================================

OPTION A: Deploy to Railway (Recommended - Easiest)
──────────────────────────────────────────────────────────────────────────────

1. Create Railway account: https://railway.app
2. Connect GitHub repository to Railway
3. Railway will:
   - Clone your code
   - Install dependencies from requirements.txt
   - Run: gunicorn app:app
   - Assign you a production URL

4. Set environment variables in Railway dashboard:
   - Go to your project → Variables
   - Add:
     SECRET_KEY=your-secret
     EMAIL_ADDRESS=your-email
     EMAIL_PASSWORD=your-app-password
     FIREBASE_WEB_API_KEY=your-firebase-key
     FLASK_DEBUG=False
     PORT=8000

5. Upload serviceAccountKey.json:
   - Option A: Add as environment variable (base64 encoded)
   - Option B: Upload as file to Railway

6. Deploy button → Watch deployment logs

OPTION B: Deploy to Heroku
──────────────────────────────────────────────────────────────────────────────

1. Create Heroku account: https://heroku.com
2. Install Heroku CLI
3. Login: heroku login
4. Create app: heroku create kidney-stone-ai
5. Set config vars:
   heroku config:set SECRET_KEY=xxx
   heroku config:set EMAIL_ADDRESS=xxx
   heroku config:set EMAIL_PASSWORD=xxx
   heroku config:set FIREBASE_WEB_API_KEY=xxx
   heroku config:set FLASK_DEBUG=False

6. Push code: git push heroku main
7. Wait for deployment
8. Access: heroku open

OPTION C: Deploy to Docker (Advanced)
──────────────────────────────────────────────────────────────────────────────

Create Dockerfile:
  FROM python:3.11-slim
  WORKDIR /app
  COPY requirements.txt .
  RUN pip install -r requirements.txt
  COPY . .
  CMD ["gunicorn", "app:app", "--bind", "0.0.0.0:8000"]

Build and run:
  $ docker build -t kidney-stone-ai .
  $ docker run -p 8000:8000 kidney-stone-ai

OPTION D: Deploy to AWS/Google Cloud/Azure
──────────────────────────────────────────────────────────────────────────────

1. Create instance (EC2, Compute Engine, App Service)
2. Install Python 3.11+
3. Clone repository
4. Install dependencies: pip install -r requirements.txt
5. Install gunicorn: pip install gunicorn
6. Start application: gunicorn app:app --bind 0.0.0.0:8000
7. Use Nginx as reverse proxy
8. Setup SSL certificate with Let's Encrypt
9. Configure firewall rules to allow ports 80/443

9. TROUBLESHOOTING
================================================================================

ERROR: "ModuleNotFoundError: No module named 'tensorflow'"
──────────────────────────────────────────────────────────────────────────────

Solution:
1. Ensure virtual environment is activated: (.venv) in prompt
2. Verify pip location: where pip (Windows) or which pip (Mac/Linux)
3. Reinstall TensorFlow: pip install tensorflow==2.20.0
4. Check Python version matches 3.10+: python --version

ERROR: "FileNotFoundError: serviceAccountKey.json"
──────────────────────────────────────────────────────────────────────────────

Solution:
1. Verify file exists in project root:
   Windows: Test-Path serviceAccountKey.json
   Mac/Linux: ls -la serviceAccountKey.json

2. If missing, download from Firebase Console:
   - Google Cloud Console → Service Accounts
   - Generate new key → Download JSON
   - Place in project root

3. Check file is not empty: file size should be >1KB

ERROR: "SSL: CERTIFICATE_VERIFY_FAILED" when sending emails
──────────────────────────────────────────────────────────────────────────────

Solution:
1. Update EMAIL_PASSWORD in app.py to app-specific password (not Gmail password)
2. Enable 2FA on Google Account
3. Generate new app password from https://myaccount.google.com/apppasswords
4. Update EMAIL_PASSWORD in app.py line 214

ERROR: Port 5000 already in use
──────────────────────────────────────────────────────────────────────────────

Solution:
Windows:
  PowerShell> netstat -ano | findstr :5000
  PowerShell> taskkill /PID <PID> /F

Mac/Linux:
  $ lsof -i :5000
  $ kill -9 <PID>

Or run on different port: python app.py --port 8000

ERROR: "The model.keras file is corrupted"
──────────────────────────────────────────────────────────────────────────────

This is expected! The model recovery system will automatically:
1. Detect corruption
2. Build fresh VGG16 architecture
3. Load trained weights automatically

The app will still work correctly. To fix:
1. Re-download model from training pipeline
2. Or keep using automatic fallback (works fine)

ERROR: "Firebase initialization failed"
──────────────────────────────────────────────────────────────────────────────

Solution:
1. Verify serviceAccountKey.json is valid JSON:
   python -c "import json; json.load(open('serviceAccountKey.json'))"

2. Check Firebase credentials are not expired
3. Regenerate key from Firebase Console
4. Restart application

ERROR: "Images not uploading"
──────────────────────────────────────────────────────────────────────────────

Solution:
1. Check file format is PNG/JPG/JPEG/JFIF
2. Verify file size < 16MB (app.config['MAX_CONTENT_LENGTH'])
3. Check uploads/ folder exists and is writable
4. Check browser console for JavaScript errors (F12)

ERROR: "Email verification code not received"
──────────────────────────────────────────────────────────────────────────────

Solution:
1. Check EMAIL_ADDRESS in app.py line 213
2. Check EMAIL_PASSWORD in app.py line 214 (must be app-specific password)
3. Check spam/junk folder
4. Wait 1-2 minutes, emails can be delayed
5. Check SMTP connection in terminal logs for errors
