            HOW TO RUN PROJECT 
===========================================

This short guide assumes you have received a ZIP archive of the
`Kidney_Stone_Detection_Project` folder and that the Firebase
credentials (`serviceAccountKey.json`) are already included in the
archive alongside the source code.

Steps to get up and running in minutes:

1. **Download & Unzip**
   • Save the ZIP file to your computer.
   • Right‑click → Extract All (Windows), or use `unzip` on macOS/Linux.
   • Enter the extracted directory:
        ```
        cd Kidney_Stone_Detection_Project
        ```

2. **Install Python**
   • Ensure Python 3.10 or newer is installed and on your PATH.
   • Verify with `python --version` (should print 3.10+).

3. **Create virtual environment**
   • Windows (PowerShell):
        ```powershell
        python -m venv .venv
        .\.venv\Scripts\Activate.ps1
        ```
   • macOS/Linux:
        ```bash
        python3 -m venv .venv
        source .venv/bin/activate
        ```
   • Your prompt will change to show `(.venv)`.

4. **Install dependencies**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
   The list includes Flask, TensorFlow, NumPy, OpenCV, Firebase Admin, etc.


5. **Run the application**
   ```bash
   python app.py
   ```
   • The server will start on `http://localhost:5000`.
   • Look for `Model loaded and compiled successfully!` in the logs.

6. **Use the web UI**
   • Open your browser to `http://localhost:5000`.
   • Register or log in (email verification is sent via the preset
     Gmail address).  
   • Click "Start Detection" and upload an image to see results.

7. **Stop the server**
   • Press `Ctrl+C` in the terminal where the app is running.

### Notes

• All required Firebase credentials are pre‑included; you do not need to
  edit any configuration.
• The `uploads/` directory is created automatically for storing images.

That’s it!  You now have a working copy of the KidneyStone AI
application running locally.
